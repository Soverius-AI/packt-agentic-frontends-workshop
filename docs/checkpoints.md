# Presenter checkpoints

This branch is the presenter starter derived from completed `07-human-in-loop`.
Use [the cue sheet](../workshop/cue-sheet.md) and
[presenter guide](../workshop/README.md) for milestones 01–07.

`pnpm workshop:select NN` restores the small presenter files, with a backup of
their previous contents. It does not switch Git branches or reset SQLite data.
The numbered branches remain separate cumulative reference implementations;
they are not merged into this branch or each other.

See [readiness](../workshop/readiness.md) for adding A2UI and later topics.
The original `docs/step-*` documents and workshop blueprint are source design
history; their three-hour, participant-oriented or React descriptions do not
override the three-day presenter-led format documented under `workshop/`.
